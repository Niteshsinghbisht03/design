Python Raster-to-Fillable-Line-Art Vectorizer

Converts raster images (ceramic tiles, illustrations, or sketches) into production-grade scalable SVG vector line art with:

  • Smooth Uniform-Width Black Linework: Master ink contours (#000000, fill-rule="evenodd").
  • 2px Tucked Fill Regions: Pre-segmented closed white paths (#ffffff) tucked 2px beneath black outlines to prevent white gaps or bleeding seams when textures are applied.
  • 8-Fold D4 Dihedral Symmetry: Flawlessly averages 4 rotations × 2 reflections for symmetrical square ceramic tiles.
  • Catmull-Rom Splines with Sharp Corner Detection: Smooth Bezier curves that keep geometric corners sharp when turning angles exceed 35°.
Quick Terminal Commands:
# 1. Line art mode (B&W drawings)
python tile_to_fillable_svg.py my_sketch.jpg my_tile.svg --mode lineart

# 2. Colored tile mode with 8-fold symmetry
python tile_to_fillable_svg.py tile_photo.jpg my_tile.svg --mode colored --symmetric

# 3. Live Vectorizer Web Server (enables 1-click drag & drop in this app)
python tile_to_fillable_svg.py --serve
